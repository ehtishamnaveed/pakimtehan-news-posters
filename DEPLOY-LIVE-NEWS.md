# Live News: production deploy (pakimtehan.com · dashboard.pakimtehan.com · api.dashboard.pakimtehan.com)

All three sit on the same Namecheap hosting, so the API server can write into the website's folder.
Do the steps in this order. Nothing here starts the daily poster run: the Cloudflare cron stays paused
until you decide the schedule.

## 0. Find three paths in cPanel (File Manager)
- **Website web root**: the folder of pakimtehan.com that holds `spa.html` after a website deploy
  (usually `/home/<user>/public_html`).
- **API app folder**: the Node.js app for api.dashboard.pakimtehan.com (cPanel → Setup Node.js App).
- **News Posters folder**: create `/home/<user>/News Posters` (outside `public_html`, permissions 750).
  This is the only copy of approved stories and posters. Include it in backups.

## 1. Cloudflare Worker
```
cd cloudflare/worker && wrangler deploy
```
- Generate a NEW production token: `openssl rand -hex 32`. Never reuse the local one.
- `wrangler secret put STORE_TOKEN` (the new token) and `wrangler secret put GITHUB_TOKEN`
  (a fine-grained token: this repo only, Actions read/write; then revoke the old classic token).
- GitHub repo → Settings → Secrets: `POSTERS_STORE_TOKEN` = the same new token; Variables: `POSTERS_STORE_URL`.
- Do NOT set `DEV_SKIP_DISPATCH` on production (it stops edits from re-rendering).
- Check: `curl -H "Authorization: Bearer <token>" https://pakimtehan-posters.<sub>.workers.dev/usage`
- Keep `crons = []` until the schedule is decided.

## 2. Push the posters repo to `main`
The Worker starts the GitHub Actions from `main`; the new templates, story fields, field regions and edit logic
must be there first. (Pushing does not start a run.)

## 3. API server (api.dashboard.pakimtehan.com)
Deploy the `pi_user_server` code, then set in the app's environment:
```
NEWS_POSTERS_STORE_URL=https://pakimtehan-posters.<sub>.workers.dev
NEWS_POSTERS_STORE_TOKEN=<the new token from step 1>
NEWS_POSTERS_STORAGE_DIR=/home/<user>/News Posters
NEWS_SEO_WEBROOT=/home/<user>/public_html        # the website web root from step 0
NEWS_SITE_URL=https://pakimtehan.com
ALLOWED_ORIGINS=https://pakimtehan.com,https://www.pakimtehan.com,https://dashboard.pakimtehan.com
# optional, for Bing: NEWS_INDEXNOW_KEY=<any 8-128 character key>
```
- Delete the old `NEWS_POSTERS_GITHUB_*`, `NEWS_POSTERS_SYNC_*` and `NEWS_POSTERS_LOCAL_DIR` if present.
- Never set `DISABLE_SUBSCRIPTION_CRON` in production.
- No database change: the old `news_posters` table is unused (drop it by hand if it exists).
- Restart the Node app. The log must show `[NewsSeo] Writing Live News pages into /home/<user>/public_html`.
- Check: `curl https://api.dashboard.pakimtehan.com/api/v3/live-news` → `{"success":true,"items":[],...}`

## 4. Dashboard (dashboard.pakimtehan.com)
`npm run build` and upload `dist/`. Make sure no `.env.local` is present on the build machine.

## 5. Website (pakimtehan.com)
`npm run build` and upload `dist/`. Make sure no `.env.local` is present (it would point the site at localhost).
- Keep `spa.html`, `.htaccess`, and anything the API wrote: `_pages/live-news*`, `live-news/posters/`,
  `live-news-sitemap.xml`, `news-sitemap.xml`. If a deploy removes them, the API rewrites them within 20 minutes.
- `robots.txt` is regenerated by the build and already lists both Live News sitemaps.

## 6. First real test
1. Start ONE daily run when you are ready (Actions → "Daily posters (free AI)" → Run workflow).
2. Dashboard → News posters: open a poster, edit something, "Update poster image" (takes about a minute), approve.
3. Check the News Posters folder has `<date>/<id>.jpg` and `<id>.json`, and the poster is gone from Cloudflare (`/usage`).
4. Open `https://pakimtehan.com/live-news/<slug>`: View source must show the title, canonical, JSON-LD and the article text.
5. Open `https://pakimtehan.com/live-news-sitemap.xml` and `news-sitemap.xml`.
6. Run Google's Rich Results Test on the story URL.

## 7. Search engines (once)
- Search Console → Sitemaps → add `live-news-sitemap.xml` and `news-sitemap.xml`.
- Optional: Bing Webmaster Tools (import from Search Console) and `NEWS_INDEXNOW_KEY`.

## Rollback
- Website/dashboard: re-upload the previous `dist/`.
- Server: redeploy the previous code. Approved stories stay safe in the News Posters folder.
- Turn the SEO writer off at any time by removing `NEWS_SEO_WEBROOT` and restarting; existing pages stay in place.
